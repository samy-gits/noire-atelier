# NOIRÉ ATELIER — Vanilla HTML/CSS/JS

This is a static rebuild of the uploaded Vite/React project.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layouts
- `script.js` — navigation, product/journal modals and enquiry form
- `assets/images/` — original images extracted from the uploaded project

## Run
Open `index.html` in a browser, or serve this folder with any static file server.

No npm install, Vite, React, TypeScript or build command is required.

## Before using for a real business
Replace the demo WhatsApp number `919000000000`, email, location, opening hours, social links, prices, fictional copy and demo testimonials/content.
The enquiry form builds a WhatsApp message; it does not store submissions.
